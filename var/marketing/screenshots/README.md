# StarLoom marketing screenshots

Well-known marketing images for the README and indexers.

```bash
# With the Vite SPA already running at https://localhost:5173:
make shoot

# Or from the repo root (same capture, chromedriver shim applied):
make screenshots

# Refresh the indexer manifest only:
make manifest
```

`screenshot-manifest.yaml` is generated from `screenshots.ini` — do not edit it by hand.
